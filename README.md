# What's This For?

This dashboard is designed for companies to monitor operating performance by visualizing financial statements and key ratios using Power BI.

The dataset is sourced from TSMC's public financial statements covering 2024Q1 through 2026Q2. As a result, this dashboard doesn't include forward-looking forecasts or market value metrics. Such insights can be visualized using additional internal and market data.

This project showcases data visualization skills for portfolio purpose. Due to static preview limitation, please download the Power BI file for an interactive experience.

Any feedback or thoughts are greatly appreciated. Feel free to connect with me!
